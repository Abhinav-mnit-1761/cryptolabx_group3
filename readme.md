# CryptoLabX

## Project Overview

CryptoLabX is a modular cryptography toolkit developed as part of the Cryptography Laboratory course. The objective is to build a reusable software framework that will gradually include classical ciphers, modern cryptographic algorithms, cryptanalysis tools, and utility modules. This assignment establishes the project structure and basic functionality.

## Features Implemented

- Menu-driven command-line interface
- File analysis
  - Character count
  - Word count
  - Line count
  - Unique character count
  - Letter frequency
- Execution logging
- Organized modular project structure
- Dataset folder containing sample text files
